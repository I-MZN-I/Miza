# AssetPro - AI Property Management

AssetPro is a modern, AI-powered real estate and property management platform. It harnesses the power of AI to optimize your real estate investments, providing smart analytics, predictions, and automation for the modern property owner.

## Key Features

- **Property Management:** Easily manage your real estate portfolio, tenants, and lease agreements.
- **AI Assistant:** Get AI-driven price estimations, insights, and automated support to make informed decisions.
- **Smart Analytics & Reports:** Visualize your portfolio's performance with interactive charts and comprehensive reports.
- **Dynamic Dashboard:** A smart overview of your active properties, expenses, and overall metrics.

## Tech Stack

- **Framework:** [Next.js](https://nextjs.org/) (App Router)
- **Styling:** [Tailwind CSS](https://tailwindcss.com/) & [Radix UI](https://www.radix-ui.com/)
- **Backend & Database:** [Firebase](https://firebase.google.com/) (Firestore, Auth)
- **AI Integration:** [Genkit](https://github.com/firebase/genkit)
- **Charts:** [Recharts](https://recharts.org/)

## Getting Started

1. Clone the repository and install dependencies:
   ```bash
   npm install
   ```

2. Set up your Firebase and environment variables in `.env.local`.

3. Run the development server:
   ```bash
   npm run dev
   ```

4. Open [http://localhost:9002](http://localhost:9002) in your browser to see the result.
