# **App Name**: Estate AI

## Core Features:

- Smart Expense Categorization: AI automatically tags uploaded bills/receipts with expense categories (maintenance, utility, tax, etc.), displays AI confidence level, and allows manual correction.
- Rent Prediction: AI suggests optimal rent value for each property based on area demand and past performance; displays current rent vs AI-recommended rent with insight text.
- Document Intelligence: AI auto-extracts tenant name, rent amount, lease duration, and renewal date from uploaded lease documents and visually highlights the extracted data.
- AI Chat Assistant: Floating chat button allows users to ask questions like 'Total income this month?' Responses appear in conversational UI with charts and cards.
- AI Budget Planner: AI suggests monthly savings goals, expense limits, and investment planning tips in a smart insight panel.
- Auto Report Generator: One-click 'Generate AI Report' button creates a PDF report with property summary, income/expenses/profit charts, and AI insights. The report is shown in a preview before download. The LLM acts as a tool when deciding when to incorporate insights into the report.
- Property Dashboard: Displays a list of properties with building name, location, image, total income, expenses, and profit.

## Style Guidelines:

- Primary color: Soft Emerald (#50C878) to evoke trust and financial stability.
- Background color: Dark, desaturated green (#1A3324) for a premium, modern feel (about 20% saturation).
- Accent color: Soft Gold (#D4AF37), analogous to green, to highlight key information.
- Body and headline font: 'Inter', a grotesque-style sans-serif, for a modern, neutral, and objective feel.
- Clean spacing and rounded cards for an elegant and professional layout.
- Smooth expand/collapse animations for property cards and subtle fade + slide transitions between pages.
- Minimalist icons for navigation and property details.
